Scope and address proof
- M>1, K2048/inter1536/N2048, 1..64 COMPACTED experts, nonempty all-native TL2,
  no affine weights, SiLU, existing hmx_inline alignment predicate true.
- M1, Gemma K2816/inter704, GeGLU, mixed/non-native/affine weights, E>64 and
  unproven ranges use the original loops. Standard non-Hexagon alignment helper
  returns false, so its no-op inline packet cannot be selected.
- GU: 64 increasing kt values, 96 column tiles. The last activation packet ends
  at act_off+64*2048; the last weight packet ends at w_gu_off+64*96*512.
- DN: 48 increasing kt values, 64 column tiles. The last weight packet ends at
  w_dn_off+48*64*512; both existing mid banks together end at mid_off+2*48*2048.
- Wide uint64 comparisons bound those spans against successive existing layout
  regions and the arena. Existing hmx_inline validates act/mid 2048-byte and
  both WH bases 128-byte alignment; all later offsets preserve those alignments.
- Indexed addresses only form pointers passed to a real packet. No unused
  increment after the last issue can construct a pointer beyond the allocation.
- Clear, increasing kt packet order, readout, expansion submit/wait, epilogue
  submit/wait, output/scatter, error draining and all arithmetic stay in place.
  No allocation, cache, reader, scratch-size, C16, preload or storage change.

Actual v81 -O3 -Wall -Werror code generation
- Both original GU/DN inner loops: 6 packets per two HMX issues, one stack load
  of the WH stride and two descriptor constants per pair.
- New leaf: 4 packets per two HMX issues, no inner-loop stack access, descriptor
  constants established outside the loop. Caller frame 17152 B remains 17152 B;
  leaf frame is 0. Extra heap/VTCM/persistent metadata: 0.
- Gemma fallback's GU/DN kt loop retains the 6-packet/two-issue structure and one
  stride reload. However each accumulator tile now has a leaf-condition load
  and predicate branch, register allocation/code placement also changes. This
  is NOT a claim of unchanged Gemma performance. No Gemma device run was made.
- codegen/{baseline,candidate}-command.json records exact full-TU commands.
  Full asm/.su are baseline.s, candidate.s, baseline.su, candidate.su at this
  directory's top level. codegen/*-inner.s and *-dispatch.s expose the evidence.
- 104.642 ms in the older normal MoE MM probe is clear+issue+loop including
  required HMX work, not removable scalar overhead. Do not multiply it by the
  packet reduction ratio. HMX stalls can already hide the old scalar packets;
  call/return and changed overlap can outweigh the reduction (as the separate
  FC experiment showed). Parent must decide on normal device A/B.

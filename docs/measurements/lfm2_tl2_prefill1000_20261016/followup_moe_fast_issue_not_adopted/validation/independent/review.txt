Scope and source proof
  Only the native all-active-TL2, non-affine SILU LFM 2048/1536/2048 M>1
  HMX route with 1..64 compact expert slots takes the leaf. The existing
  alignment check covers both activation/weight base pairs. The normal model
  compacts virtual experts in lfm2_moe_layer.cpp; v1's E==64 guard would have
  missed most normal calls. That superseded source-only result is archived,
  and final validation refers only to v2.

  GU uses 64 K tiles x 96 column tiles. Each activation packet is 2048 B,
  each weight packet 512 B, and the weight step is 49,152 B. Its highest
  packet endpoint is exactly 131,072 B in activation and 3,145,728 B in GU.
  DN uses 48 K tiles x 64 columns, a 32,768 B weight step, 98,304 B per mid
  bank and 1,572,864 B total weights. pp is 0 or 1, so both mid banks fit
  before result_off. The uint64 guard arithmetic checks ordered, disjoint
  ranges through result_off<=arena. These small fixed products also fit DSP
  32-bit size_t. The leaf forms indexed pointers only for actual packets,
  never the unused final column-offset pointer beyond the region.

  Ascending kt and the existing volatile HMX packet (including its memory
  clobber) are unchanged. Accumulator clear/readout remain at the original
  call sites. All DMA/expansion completion waits precede the same consumers;
  the leaf is synchronous and keeps no pointer. Worker jobs, stage-ring
  ownership, postprocessing/quantization, expert order, error cleanup and
  allocations are unchanged. The i24/native-source staging choices change
  neither these activation/weight offsets nor packet order.

  Gemma's 2816/704 geometry, M1, affine, GeGLU, mixed-native formats and
  expert counts outside 1..64 retain their old loops. Host builds have
  hexkl_hmx_mm_aligned()==0 and do not call the production no-op inline
  primitive. The optional noinline annotation is compiler-guarded; no new
  platform APIs or headers were added.

Limits
  The host harness uses scalar HMX/HVX quant/dequant stand-ins. DMA and pool
  jobs execute immediately; a submitted foreground job remains logically
  pending until the matching wait. This checks packet/control parity and
  logical retirement, not real concurrency or silicon DMA/cache visibility.
  Hexagon-only i24 staging is not run.
  Existing scalar swiglu_det.h signed exponent shift suppression is limited
  to standin/hvx_scalar.c; actual kernel TUs retain all sanitizer checks.
  M1 fixture is HMX fallback (flags0); actual native M1 returns earlier.
  No new Gemma device comparison was performed. Parent alone owns phone,
  root changes, normal A/B, exact model IDs and memory/settings validation.

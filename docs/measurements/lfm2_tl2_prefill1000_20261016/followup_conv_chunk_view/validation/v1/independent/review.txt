Source/lifetime/order proof
The outer gate requires AArch64,2048 rows,K=C=N2048,affine input/output weights,
FP32 contiguous input/projection/gated/output,!compare and supported backend.
It excludes an HTP-owned continuation from>0. Other prompts, Gemma, unsupported
backends and overlapping tensors follow the original path. No public API or
platform-specific headers are added; non-AArch64 builds exclude the new helper.

Before any RPC, projection/gated/output/state writes are pairwise disjoint and
disjoint from the whole input and convolution weights. Each view is validated
against still-live input,gated,output,state and weights. An unusable view is
materialized by existing sync_to_host before CPU writes.

Projection rows are local to each chunk (r-first); gated history is global.
Rows1920/1921 therefore read gated1919/1918 and1920/1919 respectively. The
per-channel multiply,two FMA,postmultiply order and precise pragmas are unchanged.
ThreadManager::parallelize waits all workers and issues an acquire fence before
returning. Both pre-gate and post-gate finish before the next backend call can
reuse a retained view. No asynchronous lambda captures escape their lifetime.

A false helper return occurs before any RPC. Once started, errors propagate;
state is saved only after both chunks succeed. Output projection still follows
the state save. As before, intermediate output buffers after an exception are
not guaranteed atomic. The retry fixtures verify exact recovery and state.

Limits
The host tests extract real source but mock Tensor/backend RPC/allocation and
pool control; they do not prove DSP numerical behavior, FastRPC coherence or
model latency. Existing single-owner backend and sampled-alias contracts remain.
Real-model IDs, continuation and peak memory need root device validation. No TPS
improvement is inferred solely from the removed copies. Root source and phone
were untouched; all independent artifacts are under this /tmp directory.

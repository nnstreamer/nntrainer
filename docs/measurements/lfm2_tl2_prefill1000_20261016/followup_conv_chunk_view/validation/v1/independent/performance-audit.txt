1024 executable path
The new2048 chunk helper is not taken, but the shared postgate helper changed.
Independent Android object comparison finds callback236 ->252B, row setup28
->32 instructions (+2 scalar loads, subtraction and multiplication). The2048

Static extra work cannot by itself establish the cause or magnitude of the
normal1024 regression; no cycle or latency bound is inferred.

M1 dispatch correction
Historical independently traced NeuralNetwork's node walk: the app Conv method
still runs during native graph decode. Its arithmetic is resident in DSP;
rows==1 makes lfm_prefill false, so neither new chunk nor ranged prefill work
runs. It is inaccurate to say the whole app Conv function is bypassed. App
layout/prologue may change, and indirect effects are not excluded by this guard.
Detailed M1 instruction/layer timing proof is in the author's separate audit.

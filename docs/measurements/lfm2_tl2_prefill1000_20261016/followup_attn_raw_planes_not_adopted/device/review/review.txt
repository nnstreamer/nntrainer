API, inputs and output checks
Current attn_q_step appends full FP16 K/V, accepts FP32 Q/output, and the20stats
contract returns actual decode/prefill mode at[2], prefill block count at[17].
All dimensions/lengths fit signed API int. Shared inputs/output are allocated
through HtpBackend; cache handles are released after successful cases. Exceptions
exit unsuccessfully without SUMMARY. Root must check child exit independently.
Each case holds one session/cache for A/B/A, rewrites every K/V row fromrow0,
uses deterministic seeds(A,B=A+1,A), and poisons the complete output before each
RPC. All output FP32 exponent bits are checked finite (not std::isfinite under
fastmath). A2 must match A0 bitwise; B must differ. Dumps contain all36 outputs,
231908352B per arm. The host comparator independently rechecks every byte,
finite value, A/B/A relationship, logical extent and contiguous offset.
Q/K/V input FNV64 binds records to the deterministic inputs across arms, but is
a fingerprint, not a cryptographic equality proof. Same frozen fixture binary
and runtime identity are therefore separate prerequisites. Sinks are generated
deterministically and included in case metadata, not input FNV64.

A full2048 RPC exercises9+7 query chunks and repeated Qx/PV overlap. At1024,
qx_dequant_available is false, so full1024 covers only immediate readout.
At2048, first KV block of each query block is serial; subsequent QK output is
in the old Qx raw bank, then workers dequantize while PV uses L.acc. Existing
join precedes reuse and is retained on PV/read-error exits. A/B/A additionally
exercises cross-call cached scratch replacement; it is not a substitute for
within-call overlap. Strict actual dispatch is required because v81 SDKconfig,
layout and capacity guards can decline even for full target geometry.

Four signed plane comparisons (eight probe_cvt RPCs plus supporting APIs)
Each uses dynamicQ8,64rows,hd64,KVH1 with column tile0/1 and sign-inverted
patterns. Activation values include0/1/128/254/255, alternating and mixed bytes;
actual K is obtained from kv_dump_q. The actual wrapper requires dumpedK/V4096
and s_k/s_v/colsum64 (the stale IDL s_v grouping comment is not used).
The layout API must report[usable1,base0,stride32]. Two calls at scales
(0x6000,0x4000) and(0x2000,0), bias0,n_rep1 produce four2048B planes and the
same2048-element SDK int32 accumulator. SDK arrays are first required equal.
Then unsigned byte shifts + memcpy reconstruct int32 without signed-shift UB.
Every value is checked against SDK and an int64 dot over actual quantized K;
each probe must contain negative,positive,zero accumulators. This independently
observes the signed high byte; a scalar floating-scale model does not prove it.
The existing probe helper uses its own issue/read sequence. Its results do not
alone prove the new four-pass drain or deferred Qx ownership; full attention
bit parity plus actual branch diagnostics provide that separate evidence.
